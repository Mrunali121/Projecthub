What it looks like

An honest note on the "AI"

It is not a language model. The generator is a rule-based text heuristic that runs entirely in your browser. No external AI is called. The page itself says so ("Demo mode").

This is a static site with no backend, so there is nowhere safe to keep an API key: a real LLM integration needs a server-side proxy so the key never reaches the browser. I chose to build a heuristic that is honest about its limits rather than fake a live AI response with hard-coded output.

How a real LLM would plug in

The call would go to your own backend endpoint, which holds the key and calls the model. The front end only needs this shape (the same idea is commented in ph-ai-generator.js):

const res = await fetch("/api/ai/summarize", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ notes })
});
const { summary, actionItems, stories } = await res.json();

For a version with a real model and checks on its output, see the AI Project Portfolio Control Tower project.
